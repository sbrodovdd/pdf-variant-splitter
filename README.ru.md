# PDF Variant Splitter

[English](README.md) | **Русский**

Консольная утилита, которая режет большие PDF-сборники вариантов (например, ЕГЭ с 30 вариантами) на отдельные файлы: по одному на вариант и один с ответами.

Начало каждого варианта определяется через OCR, поэтому утилита работает и со сканами, из которых нельзя извлечь текст напрямую. За один запуск можно обработать несколько сборников.

## Как это работает

1. Каждая страница рендерится в картинку через `pypdfium2`.
2. Верхняя часть страницы распознаётся Tesseract OCR.
3. Регулярные выражения (устойчивые к типичным ошибкам OCR, например к путанице русских и латинских букв) ищут заголовки «Вариант N ... Часть 1» и «Ответы ...».
4. Варианты ищутся по порядку (1, 2, 3, ...): если номер распознан, он должен совпасть с ожидаемым, если нет, доверяем порядку.
5. PDF режется по найденным страницам через `pypdf`.

## Требования

- Python 3.9+
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) с **русским** языковым пакетом (в установщике для Windows отметьте «Russian» в разделе «Additional language data»)

## Установка

```bash
git clone https://github.com/sbrodovdd/pdf-variant-splitter.git
cd pdf-variant-splitter
python -m venv .venv
.venv\Scripts\activate        # Windows (Linux/macOS: source .venv/bin/activate)
python -m pip install -r requirements.txt
```

## Использование

Каждое задание записывается как `файл.pdf:ЧИСЛО_ВАРИАНТОВ`.

Допустим, у нас есть сборник вариантов `ege_phys_2027.pdf` с 30 вариантами:

```bash
python split_variants.py ege_phys_2027.pdf:30
```

Несколько файлов за один запуск:

```bash
python split_variants.py 2026_ege_math.pdf:36 2027_ege_math.pdf:36
```

Пример вывода (для иллюстрации):

```
=== ege_phys_2027.pdf (30 variants) ===
Pages in file: 160
Variant 1 -> page 11
Variant 2 -> page 15
...
Variant 30 -> page 143
Answers -> page 147
Saved: ege_phys_2027/ege_phys_2027_var1.pdf (4 pages)
...
Saved: ege_phys_2027/ege_phys_2027_answers.pdf (14 pages)
done
```

Для каждого PDF создаётся своя папка с его именем рядом с исходным файлом. Если один файл не обработался, остальные всё равно обрабатываются, а проблемные перечисляются в конце.

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `PDF:VARIANTS` | Одно или несколько заданий: путь к PDF и число вариантов в нём | обязателен |
| `-o`, `--output-dir` | Родительская папка для результата (внутри всё равно отдельная подпапка на каждый PDF) | рядом с каждым PDF |
| `--tesseract-cmd` | Путь к исполняемому файлу Tesseract | `$TESSERACT_CMD`, затем `PATH`, затем стандартный путь Windows |
| `--lang` | Язык Tesseract | `rus` |
| `--dpi` | Разрешение рендера | `150` |
| `--top-fraction` | Верхняя часть страницы для OCR (0-1) | `0.33` |
| `--psm` | Режим сегментации страницы Tesseract | `11` |
| `--start-page` | С какой страницы начинать (с 1) | `1` |
| `--debug` | Сохранять картинки и текст OCR в `debug_ocr/` и просматривать весь файл (запускайте для одного файла) | выкл. |

## Если что-то не работает

- `No module named ...`: зависимости установлены в другой Python, не в тот, которым запускается скрипт. Выполните `python -m pip install -r requirements.txt` тем же интерпретатором (в VS Code: **Python: Select Interpreter**).
- Часть вариантов не найдена: скрипт пропустит этот файл, ничего не сохранив, и выведет номера пропущенных вариантов. Запустите с `--debug`, посмотрите `debug_ocr/ocr_text.txt` и попробуйте увеличить `--dpi` или `--top-fraction`.

## Разработка

Код полностью снабжён аннотациями типов. Строгая проверка типов:

```bash
python -m pip install mypy types-pytesseract
mypy --strict split_variants.py
```

## Об авторских правах

Сборники ЕГЭ защищены авторским правом, поэтому PDF-файлы в репозиторий не включены (`*.pdf` добавлен в `.gitignore`). Используйте свою копию.
